Hearthledger is a household budget site that runs entirely from static files: a November dashboard with income, spending, savings rate and category charts; an editable budget planner with a 50/30/20 check; a searchable transaction ledger with an add-transaction form; savings goals with contributions; bills and subscriptions with paid/unpaid tracking; and an insights page with a six-month trend and a what-if savings calculator. Every figure is computed from the household's records, and every control updates the totals.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. To build the hand-in output instead:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
